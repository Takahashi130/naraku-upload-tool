Naraku Upload Tool

This tool uses YouTube API Services. / このツールは YouTube API サービスを利用しています。

What it is

Naraku Upload Tool is a private, command-line tool used only by the owner of the YouTube channel “奈落婆さんが戒めるカネの話” (channel ID UCPQRj9NZPNL5RLjxzS_NaRQ) to upload videos that the owner produced to that channel. It is not offered to the public, not sold, and has no other users.

What it does with the YouTube Data API

  • Uploads the owner's own finished videos to the owner's own channel (videos.insert), with the title, description, tags and visibility chosen by the owner.
  • Sets the custom thumbnail of those videos (thumbnails.set).
  • Reads back the uploaded video's status to confirm that processing finished and the visibility is correct (videos.list, channels.list, playlistItems.list).
  • When the owner asks, changes the scheduled publish time of the owner's own videos (videos.update).

Typical use is a few uploads per week and well under 1,000 API requests per day.
