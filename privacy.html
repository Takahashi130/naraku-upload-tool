Privacy Policy

Last updated: 2026-10-15

1. YouTube API Services

Naraku Upload Tool (“the tool”) uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Information handled through YouTube is also subject to the Google Privacy Policy.

2. Who uses the tool

The tool is used only by the owner of the YouTube channel “奈落婆さんが戒めるカネの話”. It has no other users and is not offered to the public.

3. Information the tool accesses

  • Through Google OAuth 2.0, the owner grants the scopes youtube.upload and youtube.readonly (and youtube.force-ssl only for the optional scheduling command, which lists the owner's private videos and sets or removes their scheduled publish time).
  • The tool reads the owner's own channel ID and title, the titles of the owner's recent uploads (to avoid uploading the same video twice), and the status, title, processing details and duration of the owner's own videos, to confirm that an upload went to the correct channel and finished processing.
  • The tool sends to YouTube only the owner's own video files, thumbnails, text and settings (title, description, tags, category, language, visibility, made-for-kids setting, and a scheduled publish time when the owner sets one).

4. How the information is used and stored

  • The information is used only to upload and confirm the owner's own videos.
  • The OAuth token is stored only on the owner's own computer (on a drive attached to it) and is never shared or sent anywhere except Google.
  • When the owner chooses, the tool writes a local record of the owner's own upload (video ID, YouTube Studio link, visibility, scheduled publish time, thumbnail file name, and the owner's channel ID and title). It does not collect data about viewers or other channels.
  • The tool does not use cookies, analytics, or advertising, and does not sell or share any information with third parties.

5. Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the stored token no longer works, and the owner deletes the local token file. The local upload records contain only information about the owner's own uploads, and the owner can delete them at any time. Data obtained from YouTube API Services is refreshed or deleted as required by the YouTube API Services Developer Policies.
